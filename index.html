Add Shortcut to Home Screen

This will show Cal icon + small Chrome badge and open inside Chrome

  1. Tap ⋮ (3 dots) top-right in Chrome
  2. Tap Save and share or Add to Home screen
  3. Tap Create shortcut or Add to Home screen
  4. Tap Add → You will see icon with Chrome badge
